METHOD & SOURCES

方法与来源

网页展示的是带参数来源标记的参考情景估算，不是阿里数据中心的电表实测。

三层电量模型

E_IT = E_GPU + E_server_nonGPU
E_data_center = PUE × E_IT

服务器非 GPU 功率按训练 GPU 小时折算，当前主结果使用 H100 575 W/GPU、B200 787.5 W/GPU。

参数来源

  • H100 GPU 上限与 DGX H100 整机功率：NVIDIA 官方规格。
  • B200 GPU 与 DGX B200 整机功率：NVIDIA 官方规格。
  • PUE 1.56：Uptime Institute 2024 行业平均。
  • PUE 1.40：高效大型设施敏感性情景。

数据说明

周统计按连续 7 个相对 trace day 分组，最后一周是第 182–184 天。每个小时段使用区间左端标记，例如 0 代表 00:00–01:00。

完整参数表和方法文档可以在“数据下载”栏目中下载。
